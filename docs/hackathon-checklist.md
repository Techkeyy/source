# Hacktoberfest 2026 Week 2 Checklist

Updated: 2026-10-14 (Africa/Lagos)

This is a planning checklist, not a submission claim.

## Deadline

- [x] Official challenge page checked.
- [x] Contest cutoff recorded as October 18, 2026 at 11:59 PM PDT.
- [x] Lagos conversion recorded as October 19, 2026 at 7:59 AM WAT.
- [ ] Owner independently confirms eligibility, DEV membership, and final
  submission timing before implementation.

## Required entry evidence

- [ ] New project and repository created during the challenge window.
- [ ] Open-weight model or open-source AI is central to the working product.
- [ ] DEV submission post uses the required template and challenge tags.
- [ ] Public repository link or embed.
- [ ] Public deployed project link or video demo.
- [ ] Explanation of why open innovation matters for Source.
- [ ] Any post-deadline commits disclosed if applicable.
- [ ] Team DEV handles listed if more than one person contributes.

## Source-specific product evidence

- [ ] Real URL-first analysis from the deployed user path.
- [ ] Grounded profile with source excerpts and inference labels.
- [ ] User review and confirmation.
- [ ] All four customer categories materially affect discovery.
- [ ] Real permitted source-linked results.
- [ ] Match explanations show source and profile evidence.
- [ ] Editable proposal uses confirmed claims only.
- [ ] Saved opportunity survives refresh and a later sign-in.

## Partner-category evidence

- [ ] Gemma model call recorded and visible in the product path.
- [ ] Render deployment recorded.
- [ ] MongoDB Atlas persistence recorded.
- [ ] Any $100 category is entered only if the technology is genuinely used
  and its required proof is available.
