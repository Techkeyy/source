# Eligibility and Classification Evidence

The BlueTuskr opportunity remains classified as `freelance-or-contract`
because its source text includes explicit part-time contractor evidence. Source
does not convert that classification into a claim that a particular user is
eligible.

The source contains location and availability restrictions. Source does not
infer them from the company description, does not treat “Probably worldwide”
as definitive, and does not infer US-only eligibility merely from a US-based
team. The card now says:

> Eligibility is not verified by Source. Check the original listing for
> location, schedule, and availability requirements before acting.

The original listing remains one click away. No new profile fields or
eligibility engine were introduced. Unknown employment types remain excluded
from qualified opportunity results, and the existing Vytalize regression
continues to classify the salary/benefits listing as `full-time-employment`.
