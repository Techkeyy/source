# Translation decisions

## Kept from the reference's composition

- Warm paper-like canvas and white header.
- Serif editorial display type paired with a practical sans interface type.
- Large split hero with a strong left-to-right reading direction.
- Rounded white surfaces, low-noise borders and restrained shadows.
- A clear three-step story below the primary action.
- Responsive stacking at small widths rather than horizontal scrolling.

## Deliberately changed

- Findor's home-services marketplace language became Source's evidence-backed
  freelance opportunity language.
- The reference's service search became URL-first onboarding because Source
  begins with the user's public work.
- The reference photography and service cards became original SVG workflow art,
  grounded evidence panels, four customer-type controls and source-linked
  opportunity cards.
- “Verified pros” language was not reused. Source labels evidence, suggestions,
  unconfirmed signals and source classifications separately.
- No copied Findor logo, wordmark, photo, text, service taxonomy or component
  code is used.

## Product truth constraints

- Source never claims to guarantee clients, payment, outreach, or hiring.
- Website-derived claims stay attached to visible evidence excerpts when the
  current response contract provides them.
- User edits are labeled as user control, not external verification.
- Potential buyers remain public signals; the first release prioritizes
  service-provider discovery.
- The provider line is visible so the user can see whether live sources were
  queried.
